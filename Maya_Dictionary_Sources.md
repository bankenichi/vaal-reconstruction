# Maya Dictionary Sources — Catalog for the Vaal Reconstruction Project

**Purpose.** Standing reference of digitized Maya dictionaries available for root-checking
the Vaal conlang corpus. Primary host is the *Filosofía Maya* repository (compiled by
"will_meex," arq.will.mex@gmail.com), which serves each title as a direct `.pdf` download.
Keep this file as the master sourcing index; fold individual titles into
`Vaal_Reconstruction.md`'s bibliography as they are actually cited.

**Repository landing page (cite as the source-of-sources):**
Filosofía Maya. (2021, July 31; updated 2026-01-14). *Diccionarios de las lenguas mayas.*
https://filosofiamaya.com/2021/07/31/diccionarios-de-lenguas-mayas/

## Status of the three open Text 4 tokens (this pass)

The file you uploaded (`...DOKUMEN_PUB.html`) is the dokumen.pub **landing page**, whose
"citation preview" is a *scattered, OCR-degraded sample* of Cordemex pages — not the complete
dictionary. It covers parts of the CH/T/X sections but skips the pages these tokens fall on, so
it could **not** confirm any of the three. Findings, with the caveat that the definitive check is
the full Cordemex PDF linked above:

- **cheyel** — *Not in the preview as a headword* (the only `CHEY` strings are inside
  *ba'alche'ya'n* "bestiality" < *ba'alche'* "beast"). Reachable sources give strong candidates to
  test against the in-game line: **chéel / che'el / ch'el** "rainbow" (well attested; also the
  toponym Ch'el "Rainbow City"); **che'el** "magpie" or adj. "fair/blond/redheaded" (Hippocrene
  phrasebook); **che'eh** "laughter / to laugh." Collateral from the preview: *u che'el k'ab* =
  the long shaft/bone of the arm (< *che'* "wood/stick"). **Unresolved — candidate set only.**
- **a'tul** — *Not in the preview* (every `atul` string is Spanish *carátula*/*tarántula* in glosses).
  Lead: the Yucatec **animate numeral classifier -túul** (*hun-túul* "one [animate being]"); the
  unexplained *a'-* onset parallels the open morphology on *Otsuks*. **Unresolved.**
- **Axba** — *Not in the preview* (the one `AXBA` string is inside *haxba* "to twist oneself" <
  *hax* "to drill/twist" — almost certainly a false friend). Likely a **proper name** (cf. the
  randomized sergeant names) rather than a common-noun lookup. **Unresolved — probably onomastic.**

**Next action when ready:** run all three against the full Cordemex PDF (and Motul/Bolles for the
colonial layer); for *cheyel* specifically, match the candidate glosses to the exact sergeant
continuation line that contains it.

## Orthographic standard & modern wordlists (added this pass)

| **Normas de escritura para la lengua maya** (*U nu'ukbesajil u ts'íibta'al maayat'aan*) | Briceño Chel & Can Tec (coords.), INALI, 2014 | Official Maya orthography. Establishes that the glottalized stops are written *k', ts', ch', p', t'* (Maya has no *q*) — underwrites reading the corpus's stylised *q* as ejective /k'/ (*qexcan* ← *k'ex*; *qux* ← *k'ux*). | **Diccionario Maya (Spanish→Maya wordlist)** | modern, peninsular, INALI-style orthography | Present-day source independent of Cordemex.
